# LeetCode Journey

A personal collection of my **C++ LeetCode solutions**, built as I refresh my programming skills and improve my understanding of data structures and algorithms.

The goal isn't to collect accepted answers. It's to practice regularly, understand why an algorithm works, compare approaches, and document what I learn along the way.

## Goals

- Rebuild fluency in C++ after a break from regular programming.
- Practice solving problems independently, starting with Easy and progressing to Medium and Hard.
- Understand time and space complexity rather than only writing working code.
- Learn when to use data structures such as vectors, hash maps, sets, stacks, and queues.
- Keep notes I can revisit when reviewing a problem or technique.

## My approach to practice

1. Read the problem and understand the inputs, outputs, and constraints.
2. Try to solve it independently, even if the first approach is slow.
3. Test against examples and edge cases.
4. Analyze time and auxiliary space complexity.
5. Explore a better approach when possible and implement it myself.
6. Write down what I learned, especially mistakes or concepts I initially misunderstood.

## Notes

Solutions are written in C++ and use the class/function format expected by LeetCode. I may keep multiple approaches when they demonstrate a useful improvement. This repository documents my learning process, so explanations are written in my own words rather than copied problem statements.
